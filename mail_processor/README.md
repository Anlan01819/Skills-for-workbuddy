# 邮件处理工具 - IMAP版

## 功能说明
- 自动扫描所有未读邮件
- 下载邮件附件到本地
- 保存邮件正文（过滤HTML标签）
- 根据邮件标题创建对应的文件夹
- 自动标记邮件为已读
- 保存到运行当日的时间目录

## 支持的邮箱类型
- QQ邮箱
- 阿里云企业邮箱
- Gmail
- 163邮箱
- Outlook
- 其他支持IMAP协议的邮箱

## 使用前配置

### 1. 编辑 config.py 文件

打开 `config.py`，根据你的邮箱类型修改以下配置：

```python
# ==================== 邮箱账号配置（必填）====================
EMAIL_ACCOUNT = "your_email@domain.com"  # 你的邮箱账号
EMAIL_PASSWORD = "your_password"          # 密码或授权码

# ==================== 保存路径配置（必填）====================
BASE_SAVE_PATH = r"D:\业务通告"  # 文件保存根目录

# ==================== 邮箱服务器配置 ====================
IMAP_SERVER = "imap.qq.com"  # 修改为你的邮箱IMAP服务器地址
IMAP_PORT = 993              # 一般不需要修改
```

### 2. 不同邮箱的IMAP服务器地址

| 邮箱类型 | IMAP服务器 | 授权码获取方式 |
|---------|-----------|---------------|
| QQ邮箱 | imap.qq.com | 邮箱设置 → 账户 → 开启IMAP |
| 阿里云企业邮箱 | imap.qiye.aliyun.com | 网页邮箱 → 设置 → POP3/SMTP/IMAP |
| Gmail | imap.gmail.com | Google账户 → 安全 → 应用专用密码 |
| 163邮箱 | imap.163.com | 邮箱设置 → POP3/SMTP/IMAP |
| Outlook | outlook.office365.com | Microsoft账户 → 安全 |

### 3. 获取授权码/应用专用密码

大多数邮箱需要使用**授权码**或**应用专用密码**代替邮箱密码登录：

- **QQ邮箱**：设置 → 账户 → 开启IMAP/SMTP服务 → 获取授权码
- **阿里云企业邮箱**：设置 → POP3/SMTP/IMAP → 开启IMAP → 获取授权码
- **Gmail**：Google账户 → 安全 → 验证两步 → 应用专用密码

## 运行方式

## 常见问题

**Q: 登录失败怎么办？**
A: 
- 确认邮箱账号和授权码是否正确
- 确认IMAP服务已在邮箱网页端开启
- 授权码可能有有效期限制，请在网页端重新获取

**Q: 没有找到未读邮件？**
A: 程序默认只处理未读邮件，如果需要处理已读邮件，可以修改代码中的 `AND(seen=False)` 为 `AND()`

**Q: 附件下载失败？**
A: 检查保存目录是否有写入权限，部分大文件可能被邮箱服务器限制
